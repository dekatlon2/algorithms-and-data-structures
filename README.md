# Algorithms and Data Structures

Three C++ projects implementing data structures and algorithms from scratch, without STL containers. Algorithms and Data Structures course, April–May 2026.

- **Project 1** – treap (randomized BST) with subtree aggregates (sum, count, min/max ID) for fast range queries.
- **Project 2** – task scheduling on parallel machines with a custom dynamic array and sorting; computes makespan (Cmax) and total completion time (ΣC).
- **Project 3** – minimum-cost bipartite matching (Hungarian algorithm) on an adjacency-list graph, with BFS bipartiteness check.
